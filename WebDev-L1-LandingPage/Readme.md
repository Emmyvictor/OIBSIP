# Ferrywell: Landing Page

**Track:** Web Development & Designing, **Level 1 · Task 1**
**Stack:** HTML5 and CSS3 only (no JavaScript)

A static landing page for Ferrywell, a fictional Lagos lagoon ferry service.

## Feature checklist

- [x] Sticky navigation bar with 4 links (Routes, How it works, Riders, Contact)
- [x] Hero with headline, subheadline and call-to-action button
- [x] 3 content sections: Routes, How it works, What riders say
- [x] Footer with placeholder contact and social links
- [x] Consistent colour palette (CSS variables in `:root`)
- [x] Responsive layout using Flexbox and Grid, tested down to 360px wide
- [x] `box-sizing: border-box` set globally, with deliberate padding and margins
- [x] Typography with a heading font (Bricolage Grotesque) and a body font (Public Sans), at several sizes

## Run it

Open `index.html` in any browser. Fonts load from Google Fonts, with system font fallbacks if offline.

## Files

- `index.html` – page structure and content
- `style.css` – all styling
- `screenshots/` – desktop and mobile captures

## Notes

Brand name, fares, quotes and contact details are placeholders.
